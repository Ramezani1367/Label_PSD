# PSD Label Exporter — ساخت خودکار فایل exe با GitHub

این مخزن، نسخهٔ ویندوزی برنامهٔ «سامانه خروجی لیبل‌ها» را **خودکار** می‌سازد.
خروجی به‌صورت **onedir** است: یک فایل `PSD-Label-Exporter.exe` به‌همراه چند فایل کنارش
(پوشهٔ `_internal`) — این حالت باعث می‌شود اجرای برنامه **سریع** باشد و هر بار
چیزی در حافظهٔ موقت باز نشود (برخلاف حالت تک‌فایلی که هر اجرا چند ثانیه طول می‌کشد).

---

## راه‌اندازی در ۵ دقیقه

1. وارد <https://github.com/new> شو، یک مخزن بساز (مثلاً `psd-label-exporter`).
   خصوصی یا عمومی فرقی ندارد.
2. در صفحهٔ مخزن، روی **Add file ▸ Upload files** بزن.
3. **همهٔ محتویات این زیپ را** (نه خود فایل زیپ) داخل پنجره رها کن.
   دقت کن پوشهٔ مخفی `.github` هم آپلود شود — اگر مرورگر آن را نگرفت،
   فایل‌ها را روی کامپیوتر از حالت زیپ خارج کن و کل پوشه را درگ کن.
4. پایین صفحه **Commit changes** را بزن.
   > **اگر پوشهٔ `.github` آپلود نشد** (بعضی مرورگرها پوشهٔ نقطه‌دار را نمی‌گیرند):
   > در مخزن **Add file ▸ Create new file** را بزن، در کادر نام دقیقاً این را تایپ کن:
   > `.github/workflows/build-windows.yml` و محتوای همین فایل از داخل زیپ را در آن پیست کن.

5. برو به تب **Actions** ← گردش‌کار **Build Windows EXE** خودش شروع می‌شود
   (اگر شروع نشد: روی نامش کلیک کن و **Run workflow** را بزن).
   حدود ۳ تا ۵ دقیقه طول می‌کشد.
6. وقتی تیک سبز خورد، وارد همان اجرا شو و از بخش **Artifacts** فایل
   **`PSD-Label-Exporter-win64`** را دانلود کن.

داخل زیپ دانلودشده:

```
PSD-Label-Exporter/
├── PSD-Label-Exporter.exe        ← این را اجرا کن
├── PSD-Label-Exporter-debug.exe  ← همان برنامه با پنجرهٔ کنسول، فقط برای عیب‌یابی
├── _internal/                     ← کتابخانه‌ها و فایل‌های برنامه (دست نزن)
├── اجرای-حالت-دمو.bat             ← امتحان برنامه بدون فتوشاپ
├── بستن-برنامه.bat                ← بستن نسخه‌های جامانده در پس‌زمینه
└── راهنما.md
```

اگر برنامه بالا نیامد یا مرورگر پیام `ERR_EMPTY_RESPONSE` داد، نسخهٔ `-debug` را اجرا کن؛
پیام خطا در پنجرهٔ کنسول و در فایل `run.log` کنار exe ثبت می‌شود.

کل پوشه را هرجا می‌خواهی کپی کن (مثلاً `D:\Tools\PSD-Label-Exporter`) و از
`PSD-Label-Exporter.exe` یک **Shortcut روی دسکتاپ** بساز. فقط exe را جدا نکن؛
باید کنار پوشهٔ `_internal` بماند.

## نسخهٔ رسمی (Release) — اختیاری

اگر می‌خواهی لینک دائمی برای دانلود داشته باشی، یک تگ بزن:

```bash
git tag v1.0
git push origin v1.0
```

یا از GitHub: **Releases ▸ Draft a new release ▸ Choose a tag ▸ v1.0 ▸ Publish**.
گردش‌کار خودش زیپ را به آن Release می‌چسباند.

## محتوای مخزن

| فایل | کارش چیست |
|---|---|
| `app.py` | موتور برنامه: سرور محلی، اسکن فولدرها، کنترل فتوشاپ با COM، کپی PSD و ساخت JPEG |
| `psd-label-exporter.html` | کل رابط کاربری فارسی (تک‌فایل، بدون اینترنت) |
| `bridge.js` | پل بین رابط کاربری و موتور پایتون (نوار پیشرفت، انتخاب فولدر، اجرای خروجی) |
| `build.spec` | تنظیمات PyInstaller در حالت onedir + آیکن |
| `.github/workflows/build-windows.yml` | همان چیزی که GitHub با آن exe را می‌سازد |
| `assets/icon.ico` | آیکن برنامه |
| — | پنجرهٔ برنامه در حالت app‌mode مرورگر (Chrome/Edge) و **وسط مانیتور** باز می‌شود |
| `README-fa.md` | راهنمای استفاده برای کاربر نهایی |

## ساخت دستی روی ویندوز خودت (اگر خواستی)

```bat
pip install pyinstaller pywin32
pyinstaller build.spec --noconfirm --clean
```

نتیجه در پوشهٔ `dist\PSD-Label-Exporter\` ساخته می‌شود.

---

### چند نکتهٔ مهم

* exe فقط روی **ویندوز ۶۴ بیتی** کار می‌کند و برای خروجی گرفتن به **فتوشاپ نصب‌شده** نیاز دارد.
* بار اول ممکن است Windows SmartScreen پیام بدهد (چون فایل امضای دیجیتال ندارد):
  **More info ▸ Run anyway**.
* اگر آنتی‌ویروس گیر داد، پوشهٔ برنامه را در لیست استثنا بگذار؛ این مورد برای همهٔ
  برنامه‌های ساخته‌شده با PyInstaller رایج است.
* تنظیمات و فولدرهای ثبت‌شده در `settings.json` کنار exe ذخیره می‌شوند
  (اگر آن مسیر قابل نوشتن نبود، در `%APPDATA%\PSDLabelExporter`).
